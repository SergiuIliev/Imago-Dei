# Personal AI Time Capsule: Privacy & Security Architecture

**Host Platform:** Apple Silicon M4 (macOS 27.0)  
**Classification:** Confidential Personal Identity Archive  
**Primary Invariant:** 100% Local Processing · Zero Cloud Telemetry · Local Loopback Only

---

## 1. Threat Model & Privacy Principles

A personal time capsule contains sensitive memories, private reflections, evolving beliefs, family details, and recordings of personal voice and appearance. To guarantee that this identity cannot be leaked, harvested, or commercialized:

1. **Air-Gap Capable Local Execution:** Every component—language model inference, speech recognition, vector embeddings, speech synthesis, and avatar rendering—runs locally on the host machine's hardware (Apple Silicon CPU/GPU/MPS).
2. **Zero Outbound Telemetry:** No tracking pixels, telemetry events, crash reporters, analytics SDKs (Google Analytics, Mixpanel, PostHog, Segment), or cloud API pings exist in the codebase.
3. **Loopback Network Binding:** All HTTP and WebSocket services bind strictly to `127.0.0.1` (localhost). No network port is exposed to the local area network (LAN) or public internet by default.
4. **Data Portability & Vendor Independence:** Memory data is stored in standard, non-proprietary formats: SQLite 3 relational tables, JSON files, and standard PCM WAV audio. If any model or library is discontinued, the raw personal archive remains fully intact and human-readable.

---

## 2. Network Invariants & Verification

The codebase includes an automated security audit test (`tests/test_privacy_audit.py`) that executes before every deployment:

- **Loopback Enforcement:** Validates `config.security.bind_host == "127.0.0.1"` and `config.llm.endpoint` starts with `http://127.0.0.1`.
- **Static Code Scanner:** Performs regex scans across all Python files in `core/`, `app/`, `memory/`, and `providers/` for forbidden cloud API endpoints (`api.openai.com`, `api.anthropic.com`, `posthog.com`, `google-analytics.com`, `segment.io`).
- **Cloudflare Tunnel Isolation:** While the machine runs a Cloudflare tunnel (`mac-ai`) for separate web applications, the Time Capsule application (`port 7860`) is **isolated and NOT mapped** into `cloudflared` config. Only localhost requests can access the Time Capsule.

## 3. Data Storage & Retention Policies

| Data Category | Storage Location | Retention / Persistence Policy | Cryptographic Protection |
|---|---|---|---|
| **Raw Media Files** | Configurable User Directory (Outside git) | Preserved read-only; never modified or deleted | Monitored by SHA-256 checksums |
| **Relational Archive** | `data/capsule/archive.db` | Permanent SQLite database with WAL journaling | Protected by POSIX file permissions (Staff/Sergiu) |
| **Vector Store** | `data/capsule/vector_store/` | Disposable persistent ChromaDB ONNX embeddings | Fully reindexable from canonical SQLite DB |
| **Audio Cache** | `data/capsule/audio_cache/` | Temporary synthesis cache | Ephemeral; auto-cleanable |
| **Avatar Cache** | `data/capsule/avatar_cache/` | Rendered MP4 video clips | Ephemeral; local playback |
| **Backup Snapshots** | `exports/capsule_backup_*.tar.gz` | Gzip compressed archives | Sealed with SHA-256 `manifest.json` |

## 4. Disaster Recovery & Export Security

### Cryptographic Manifests
Every backup generated by `scripts/backup.sh` or `POST /api/backup/create` includes a `manifest.json` containing:
- Creation timestamp (UTC ISO-8601)
- Archive schema version
- Per-file byte size and cryptographic SHA-256 hash

### Safe Restoration Safeguards
Before applying any backup archive:
1. **Manifest Hash Verification:** The archive's files are checked against `manifest.json`. If even a single byte differs (e.g. disk corruption or tampering), the restore operation aborts immediately.
2. **Pre-Restore Snapshot:** A timestamped copy of the active database (`archive.db.bak_YYYYMMDD_HHMMSS`) is created automatically before overwriting.
3. **WAL/SHM Invariant:** Stale `-wal` and `-shm` sidecars are cleanly cleared to prevent transactional replay over restored tables.
