history_edu Architectural Evolution: Behind-the-Scenes LLM & Memory Transformations

Detailed chronicle of behind-the-scenes transformations across language model fine-tuning, memory retrieval pipelines, speech synthesis, and verification mechanisms:

v4.0 · CURRENT

Dialectical Grounding, Parametric Fallback Bridge & Brâncuși Minimalism

October 2026
LLM & Parametric Architecture:

Fine-tuned GGUF (sergiu-time-capsule:latest) on Ollama + dual-model JEV verifier (qwen3:4b-heretic). Introduced the Parametric Fallback Bridge: when semantic retrieval confidence falls below direct threshold, the system provides transparent candidate memories and answers authoritatively from fine-tuned weights without hallucinating or refusing.

Memory & Retrieval Engine:

1,231 atomic memories and 34 temporal beliefs consolidated with a ≥ 2 corroboration requirement to prevent single-vlog supersession. Timestamped supporting evidence and dialectical counterarguments/caveats indexed per belief.

Acoustic, Voice & Microphone Pipeline:

Studio-grade mastering DSP (Butterworth 2nd-order 70Hz HP + surgical 50/60/120Hz high-Q IIR notch filters, Q=45) preserving 100% of vocal formants ≥ 85Hz without phase distortion. 16-step F5-TTS flow-matching diffusion on Apple Silicon Metal MPS, 35 pristine restored reference clips, and push-to-talk local Whisper ASR for real-time speech transcription.

Interface & Conversational UX:

Brâncuși-inspired obsidian dark aesthetic (#08090d, #0c0e14), smart paragraph breaks and inline markdown formatting for clean readability, singleton audio controller preventing overlapping playback, 1-click memory verification, and dynamic architecture timeline.

v3.0

300GB Multi-Year Alignment, Autobiographical SFT LoRA & Omniscient Era

October 2026
LLM & Parametric Architecture:

Ingestion of 288 daily vlogs across 2023–2026. Extraction of 1,847 curated SFT Q&A pairs fine-tuned directly into custom GGUF model (sergiu-time-capsule). Omniscient Longitudinal Mode (all_eras) introduced for multi-year panoramic synthesis.

Memory & Retrieval Engine:

Multi-era hybrid Reciprocal Rank Fusion (RRF) combining SQLite FTS5 BM25 with ChromaDB dense ONNX vector embeddings. 1,231 atomic memories indexed with temporal era tags.

Acoustic & Avatar Pipeline:

Persistent F5-TTS Metal MPS daemon on port 7861 with warm GPU memory caching. First audio-driven LivePortrait talking head implementation with 1024-sample AAC framing.

Key Discoveries & Gaps:

Raw audio retained background microphone electrical hum; beliefs had duplicate entries that could be superseded by a single vlog; avatar had mouth tearing at vowel extremes.

v2.0

Temporal Ingestion, Discrete Chronological Eras & JEV Verifier

October 2026
LLM & Parametric Architecture:

Prompt-grounded persona profiles across 4 life stages (Early 20s, Mid 20s, 2023, Present Day). Introduced JEV Dual-Model verification (Generator + Critic) to check grounding and honest uncertainty.

Memory & Retrieval Engine:

SQLite FTS5 full-text search combined with ChromaDB vector search. Push-to-talk Whisper ASR transcription for user queries.

Acoustic & Avatar Pipeline:

Kokoro-82M neural TTS with custom speaker tensor; fallback to macOS native speech. Static persona portrait reference images.

Key Discoveries & Gaps:

Lacked deep autobiographical fine-tuning (relied solely on RAG context); queries without exact lexical overlap triggered cold refusals rather than reasoned answers.

v1.0

Initial Prototype: Flat Context RAG & Speech Synthesis

October 2026
LLM & Parametric Architecture:

Base Ollama model with standard prompt injection; no era disambiguation; flat temporal timeline; no critic or dual-model cross-auditing.

Memory & Retrieval Engine:

Single SQLite database table with simple keyword pattern matching; manual memory entry; no vector embeddings or confidence calibration.

Acoustic & Avatar Pipeline:

Standard system speech synthesis without speaker reference conditioning; no video avatar capabilities.

Key Discoveries & Gaps:

Severe vulnerability to hallucination; inability to capture personal voice timbre or philosophical shifts across life stages.
